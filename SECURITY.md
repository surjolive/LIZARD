# Security Policy

## Supported versions

The latest release on the `master` branch is the supported version of LIZARD.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use GitHub's private security advisory flow for `surjolive/LIZARD`:

https://github.com/surjolive/LIZARD/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested fix. Remove passwords, tokens, personal data, and other secrets from the report.

We will acknowledge valid reports and coordinate a fix or mitigation before public disclosure when practical.
