## 🛠️ Developer Guide

### Build LIZARD

```bash
# Build release binary
cargo build --release

# Run tests
cargo test

# Run example
lz run hello.lz
```

### Project Structure

```
LIZARD/
├── src/
│   └── main.rs              # Main interpreter (~2100 lines)
├── tests/
│   ├── hello_program.rs     # Test programs
│   ├── collections_and_each.rs
│   ├── functions_and_repeat.rs
│   ├── while_and_boolean.rs
│   └── data/
│       └── stdlib_helpers.lz # Test data
├── docs/
│   └── LIZARD-GUIDE.md      # Complete user guide
├── editors/
│   └── vscode/
│       └── lizard-vscode/   # VS Code extension
├── examples/
│   └── hello.lz
├── release/
│   └── windows-x64/         # Pre-built binaries
├── Cargo.toml               # Rust package config
├── .cargo/config.toml       # Build configuration
├── install.ps1              # Windows installer
├── build.ps1                # Windows build script
└── README.md                # Project overview
```
