# LIZARD Code of Conduct

The LIZARD community is expected to be respectful, constructive, and welcoming.

## Expected behavior

- Be kind and professional.
- Discuss code and ideas without attacking people.
- Welcome different backgrounds and levels of experience.
- Give actionable feedback and accept correction gracefully.
- Respect project maintainers, contributors, and users.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized behavior, and deliberate disruption are not allowed.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or restrict participation when this code is violated. Serious or repeated incidents may be reported to GitHub.

Report conduct concerns privately through the repository's GitHub contact options. Do not include sensitive personal information in a public issue.
